# OPE KA Lite

Khan Academy Lite for the Open Prison Education platform.

## Overview

KA Lite (Khan Academy Lite) provides offline access to Khan Academy's educational content, offering a world-class education for anyone, anywhere - even without internet access.


## Usage

Enable KA Lite in `config.yml` (or via the interactive setup wizard `./setup.sh`):

```yaml
services:
  - ope-kalite
```

Then start services:

```bash
./up.sh
```

## Content

Video content must be downloaded separately and placed in the appropriate volume for offline access.
