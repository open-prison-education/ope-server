# OPE RACHEL

RACHEL (Remote Area Community Hotspot for Education and Learning) content server.

## Overview

Provides offline educational content from various sources including Wikipedia, Khan Academy, and other educational resources.

## Features

- Offline Wikipedia access
- Educational videos and content
- Multiple subject areas
- Web-based interface

## Usage

Enable the service:

```bash
touch ope-rachel/.enabled
./up.sh
```

## Notes

RACHEL content modules must be downloaded separately and placed in the appropriate volume.
