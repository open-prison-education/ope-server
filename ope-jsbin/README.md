# OPE JS Bin

JavaScript code playground for the Open Prison Education platform.

## Overview

JS Bin is a collaborative JavaScript debugging tool that allows students to write and test HTML, CSS, and JavaScript code in real-time.

## Features

- Live code editing
- HTML, CSS, and JavaScript support
- Code sharing capabilities
- Console output viewing

## Usage

Enable the service:

```bash
touch ope-jsbin/.enabled
./up.sh
```
