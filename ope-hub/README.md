# OPE Hub

Django-based replacement for the Student Management Console.

## Overview

OPE Hub is a modern rewrite of the SMC (Student Management Console) using the Django framework instead of Web2py. This project is currently in early development.

## Status

**Development Stage:** Early development

## Technical Details

- **Framework:** Django
- **Purpose:** Replace ope-smc with a more maintainable codebase

## Usage

This service is not yet ready for production use.

```bash
# When ready for testing:
touch ope-hub/.enabled
./up.sh
```
