# OPE GCF

GCFGlobal (GCFLearnFree.org) offline content for the Open Prison Education platform.

## Overview

GCFGlobal provides free learning opportunities to improve the technology, literacy, and math skills needed to succeed in work and life.

## Usage

Enable GCF in `config.yml` (or via the interactive setup wizard `./setup.sh`):

```yaml
services:
  - ope-gcf
```

Then start services:

```bash
./up.sh
```

## Content

GCFGlobal content must be downloaded and placed in the nginx html volume for offline access.
